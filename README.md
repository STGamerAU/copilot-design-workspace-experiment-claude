# Copilot Design Workspace Experiment

This repository is a small experiment in using GitHub Copilot across a product-design workflow.

The project is a greenfield service-appointment rescheduling experience.

The goal is not to produce a production application.

The goal is to test whether persistent, structured project context allows Copilot to support:

problem understanding
→ design reasoning
→ human decisions
→ planning
→ prototype creation
→ design review

Canonical project knowledge lives in `/project`.

The human designer makes product and UX decisions.

Copilot may analyse, propose and implement approved work, but should maintain a clear distinction between:

- known facts
- assumptions
- proposals
- human decisions
